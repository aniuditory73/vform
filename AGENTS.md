# vform

Сайт студии DTF-печати. Рабочий каталог проекта содержит Next.js App Router, TypeScript, Tailwind CSS, GSAP, Lenis.

## Визуальный стиль

- Сохраняй непрерывную тёмную сцену и композицию первого экрана из референса. Палитра: фон `#080808`, поверхность `#141414`, текст `#F2F2F0`, вторичный текст `#999999`, акцент `#FF5A1F`.
- Сохраняй контраст наклонного гротеска и оранжевого serif italic. Держи заголовок и технические подписи HTML-текстом.
- В портфолио показывай одну футболку за раз и сохраняй переключение стрелками. Показывай расчёт стоимости сразу после изменения параметров.

## Сцена и контент

- На первом экране используй статичное фото худи в композиции референса.
- Проверяй первый экран, навигацию, управление клавиатурой и вертикальную прокрутку на телефоне. Учитывай `prefers-reduced-motion`.
- Меняй тексты, работы, цены и контакты через `config/`. Публикуй только подтверждённые цены и контакты. Помечай демонстрационные работы.
- Перед сдачей запускай `npm run typecheck`, `npm run lint` и `npm run build`.
